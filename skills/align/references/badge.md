# Add the README badge

Path 7 is an optional README edit for a project using ALIGNS.md. Offer it only
when the target README can be inspected and its ALIGNS.md badge is absent.
Do not offer it in a personal-only session with no target project, after refusal,
or while deferred. A badge signals use, not certification or a benchmark score.

## Check before offering

Read the project's primary README and applicable instructions. Inspect actual
Markdown images, reference-style images and their definitions, or HTML img/picture
markup. Recognize the provided `uses-aligns.svg` asset as well as equivalent custom
or Shields badges identifying ALIGNS.md. Resolve local image paths and references
when needed. Ignore fenced examples, comments and ordinary mentions of ALIGNS.md;
these are not displayed badges. Do not count a general skills-directory or GitHub
star badge as an ALIGNS.md usage badge.

If a displayed badge is already present, mark path 7 as satisfied and omit it from
recommendations. Do not relocate or replace it merely to match this template. If
that badge is broken, report the issue and repair it only within the requested
scope; do not add a second badge. If the README is missing or unreadable, report
the prerequisite gap instead of creating a README or guessing that the badge is
absent. If presence is ambiguous, resolve the reference or explain the uncertainty
before recommending addition.

Follow the project's translation policy. An existing primary README badge with a
missing translated counterpart is a translation consistency issue, not grounds
for adding another badge to the primary README.

## Add after selection

Selecting 7 or explicitly asking for the badge authorizes this scoped edit. Do
not ask for a second permission to add it. Recheck the current file, then insert
one badge alongside existing badges, or below the title when no badge row exists.
Preserve alignment, HTML/Markdown style, and unrelated content. Apply required
translation updates with correct relative paths; do not create new translations.

Use the project's existing equivalent asset if available. Otherwise use this
static image and public project link:

```markdown
[![Uses ALIGNS.md](https://raw.githubusercontent.com/hmmhmmhm/aligns.md/main/assets/badges/uses-aligns.svg)](https://github.com/hmmhmmhm/aligns.md)
```

Do not use a token-dependent dynamic badge or include personal agreement content,
private paths, account identifiers, or credentials in the image URL. This step does
not authorize committing, pushing, publishing, or installing another skill copy.

Inspect the diff and verify that the image is outside code fences and appears only
once in the intended badge location. Check the image and destination link when
network access is available; otherwise state that remote availability was not
verified. Do not claim a rendered check without rendering. Mark the item completed
only after the edit and available checks, then use the usual remaining-path choices
and session closure rules. A badge edit does not change agreement criteria or
confirmation dates. If the badge appeared before the edit, skip the write and
report it as already satisfied.
